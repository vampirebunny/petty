Where each slot attaches

Coordinates are on the reference dog, side view facing right, ground at y 0 (head radius 21, body 92 × 48, leg width 10). Each worn file is drawn around its own origin, so it moves and scales with that body part.

SlotOrigin on rigFollows
hat(54, -88)head center; scale by headR / 21; rotates with head pitch
glasses(54, -88)head center; scale by headR / 21; rotates with head pitch
neckwear(40, -66)front of the neck under the chin; scale by headR / 21; follows neck
jacket(0, -56)body center; scale x by bodyLen / 92, y by bodyH / 48; rotates with torso
back(14, -80)withers (top of the shoulders); scale by bodyH / 48; rotates with torso
bootseach pawpaw center, y up the shin; scale by legWidth / 10; rotates with the shin
